# Sprint 1 - Descoberta e plano tecnico

Objetivo: entender a arquitetura real antes de alterar qualquer arquivo.

## Escopo

- Ler instrucoes do projeto, README, configuracoes relevantes e documentacao local.
- Usar `graphify query` para localizar relacoes entre colecao, formulario, detalhes, queries, actions, schema e componentes compartilhados.
- Identificar framework, versoes, sistema de estilos, tokens, fontes, componentes reutilizaveis, schema do banco, validacoes, integracao Supabase e testes existentes.
- Mapear os arquivos provavelmente afetados.
- Definir uma estrategia curta para banco/tipos, interface, responsividade e testes.

## Fora do escopo

- Alteracoes de codigo.
- Migracoes.
- Remodelagem visual.
- Criacao de componentes.

## Entrega

- Plano curto com:
  - arquivos provavelmente afetados;
  - mudancas de interface;
  - mudancas de banco e tipos;
  - estrategia de responsividade;
  - estrategia de testes;
  - riscos e pontos que exigem confirmacao manual.

## Validacao

- Confirmar que o escopo real foi localizado no repositorio.
- Confirmar se ha testes existentes para formulario, detalhes, queries e actions.
- Nao executar build completo nesta sprint, a menos que a descoberta indique necessidade.

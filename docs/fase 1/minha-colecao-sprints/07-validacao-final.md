# Sprint 7 - Validacao final e fechamento

Objetivo: garantir que a entrega completa esteja realmente pronta.

## Escopo

- Executar suite de validacao completa.
- Revisar regressao visual grave.
- Confirmar que Perfumista e Pais da marca nao foram adicionados.
- Confirmar que registros antigos continuam funcionando.
- Confirmar ausencia de scroll horizontal.
- Confirmar que desktop, tablet e mobile estao funcionais.
- Preparar relatorio final objetivo.

## Validacao obrigatoria

- `npm.cmd run lint`.
- `npm.cmd run typecheck`.
- `npm.cmd test`.
- `npm.cmd run build`.
- Validacao de migracoes/schema conforme ferramentas do projeto.
- `graphify update .`.

## Entrega final

- Resumo das mudancas.
- Arquivos alterados.
- Migracoes criadas.
- Componentes novos ou reutilizados.
- Decisoes importantes de UX.
- Ajustes tipograficos realizados.
- Resultado de lint, typecheck, testes e build.
- Pendencias reais, caso existam.
- Breakpoints validados.
- Riscos ou pontos para revisao manual.
